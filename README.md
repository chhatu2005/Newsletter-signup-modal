# Newsletter Signup Modal

A simple and responsive Newsletter Signup Modal built using HTML, CSS, and JavaScript as part of my Veda Technology Web Development Internship.

## Features

- Newsletter modal appears automatically after 3 seconds.
- Email input field.
- Email validation.
- Shows error message for empty or invalid email.
- Shows success message for valid email.
- Modal closes after successful subscription.
- Close button to close the modal.
- Clicking outside the modal closes it.
- Responsive design for mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
